# emacsDotfiles

## The important Emacs dotfiles: config.org, config.el, customs.el, early-init.el, init.el

My emacsDotfiles repository contains the .config files necessary to get Emacs up and running. Not only is Emacs my goto integrated development environment (IDE), I currently use it on a day-to-day basis to track my tasks, notes, and projects via Org mode. Eventhough I'm not a full-time programmer, I still enjoy hacking away at programming from time to time. The following highlights may help you in your search for the perfect IDE:
* ORG Mode
* LSP, LSP-JAVA
* EVIL
* ELPACA Package Manager for Emacs
* MAGIT
* PROJECTILE

The config.org file is the documentation version of config.el. The config.el file consists of the Emacs Lisp used to run Emacs. I hope this helps you get Emacs customized and ready to tackle the projects that matter most to you.
